# 计算说明书第二次修改协作项目

本目录用于分发、回收和统合《某污水处理厂设计计算说明书》第二次修改工作。

## 目录

- `00_公共文件/`：两版Word、修改状态表、老师意见、总计划、录音转写及标准口径说明。
- `01_任务分发包/`：十个轻量任务目录、任务报告、专用标准节选及可直接分发的ZIP。
- `02_成果回收/`：各组完成后提交Markdown报告和计算附件的位置。

教案、任务书及两本扫描手册已在仓库根目录保存，不在本项目目录重复复制：

- `../环境工程设计教案(2).pdf`
- `../设计任务书6(2).doc`
- `../第1册 常用资料(2).pdf`
- `../第5册 城市排水(2).pdf`
- `../资料索引/阅读索引.md`

任务包已经按组抽取扫描手册所需页段。队员应优先查看本组节选，仅在需要核对上下文时再根据阅读索引打开原手册。

## 开始工作

1. 先阅读仓库最新一份`任务日志/`以及本目录`00_公共文件/第二次修改分组计划_2026-09-13.md`。
2. 从`01_任务分发包/压缩包/`领取本组ZIP，或直接使用同名任务目录。
3. 阅读本组`任务报告.md`，记录开始工作时的仓库提交号。
4. 只修改本组负责的计算或说明；公共Word母版由第10组统一写入。
5. 将填写后的Markdown报告和附件提交到`02_成果回收/第XX组_主题/`。

## 协作顺序

```text
01 基线定位
  ├─ 02 流量与提升系统 ─┐
  ├─ 03 脱氮除磷算法 ───┤→ 04 A²/O、回流与鼓风机
  └─ 05 池体资料审阅 ───┘

02 + 04 + 05 → 06 配水与消毒
02 + 05 + 06 → 07 总平面与管线
02 + 05 + 06 + 07 → 08 水力高程
02—08全部冻结 → 09 位图整图重绘 → 10 统稿终检
```

第05组可与第02、03组并行做资料审阅，但使用最终流量完成尺寸校核后才能交付。第09组不得在上游参数未冻结时重绘位图。

## 具体修改安排

### 第一批：基线确认

由第01组先完成红黄标记、Excel状态、老师意见和图片问题的定位，形成统一的意见定位表。其他组以该表确定自己的修改边界。

### 第二批：三组并行准备

第02组统一平均日/最高时流量、工艺顺序、粗格栅、进厂管和提升泵；第03组审查脱氮除磷、外加碳源、碱度、污泥产率等算法及参数来源；第05组先按教案和规范审阅沉砂、初沉、二沉池的结构问题。第02、03组须交出冻结参数后，第05组再用最终流量完成池体尺寸校核。

### 第三批：生物与供气联算

第04组等待第02、03组通过后，统一计算A²/O分区、MLSS/MLVSS、SRT、回流污泥、内回流、需氧量、曝气器和鼓风机。回流泵的“6台4用2备”与“4系列各1用1备”必须在本批一次定案，不能留两套说法。

### 第四批：配水与消毒

第06组等待第02、04、05组交付，确定二沉配水井采用4井×2池或2井×4池，重算支路和管径，并统一“初沉→A²/O→二沉→接触池→控制井”顺序。次氯酸钠、接触时间、池容和分格尺寸在本批闭合。

## 每批交接条件

每组交付时必须同时提交：修改报告、依据和页码、计算过程、最终采用值、旧值/新值对照、影响范围、下游接口参数和未解决事项。下游组未收到上游冻结报告前，只能做资料准备，不能锁定最终数字或重绘位图。

## Git工作流

每位队员从最新`main`建立自己的任务分支，例如：

```text
docs/revision-group-02
```

一个分支只提交一组成果，通过PR合并。禁止直接推送`main`。第09组位图和第10组Word母版执行单文件单写者规则。
