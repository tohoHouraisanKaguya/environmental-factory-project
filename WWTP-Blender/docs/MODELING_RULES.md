# Modeling Rules

Engineering precedence: position, plan dimensions, elevations, process relationships, equipment count, then visual detail.

The following must be generated with `bpy` from JSON parameters: screens/channels, influent well, aerated grit chambers, primary clarifiers, A2/O basins, secondary distribution, radial secondary clarifiers, contact tank, long-throat flume, roads, walls, buildings, pipes, simplified screening/scraper/aerator/grit-removal machinery.

Do not use downloaded WWTP, settling-tank, or A2/O models as substitutes. External assets are only visual details. Repeated equipment must share mesh data or use instances.
