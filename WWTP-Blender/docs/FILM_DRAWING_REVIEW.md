# 第二版图纸返修记录

依据用户提供的《污水处理厂厂区总平面与管线图（第二版）》单页 A1 PDF，直接查看总图及预处理、生化、二沉出水局部后修订。原稿把多条标注 DN 的管线扩大成长明渠，且格栅外加渠端头缺少封闭，这两项做法已撤回。

| 问题 | 修改后的模型 |
|---|---|
| 格栅四角、外部渠端头漏空 | 保留原四面池壁，重建池内集配水区、两条过水槽与底板；水面限制在池壁内；外部由空心管道进出 |
| 细格栅朝向与连接不符 | 机械和清污耙转为东西向，耙的动画轴同步转换 |
| 主线误建为长明渠 | 102 段管道分别记录折点、管径、系统和依据；取消贯穿厂区的外加长明渠 |
| 初沉与生化外部接点偏离 | 同列初沉北侧接入、南侧接生化；生化内部整体转向以匹配北进南出，保留 A/B 分组 |
| 一条巴歇尔式计量槽、喉宽 1.20 m | 改为两条长喉计量渠；每条实体喉宽 1.50 m；同步修改中文字幕 |
| 缺 SL、OV | 分别补充主水 W、RAS、IR、AIR、SL、OV、加药 CHEM；OV 按图纸注明暂定并设置常闭阀片 |
| 平面相交但高程断开 | 为细格栅分流、加药和 OV 补充竖向接管；穿墙处生成开孔并检查中心线 |
| 二沉池开孔破坏底板 | 将外墙开孔与斜底板生成分开，保留坡底和集泥坑，并增加集泥坑吸泥管口 |

## 检查依据

- `FILM_DRAWING_VALIDATION.json`：直接打开保存后的场景，射线检查 G1/G2 共八个实体角墙、水体平面包络、两条实体计量渠喉宽，以及四组生化池接口方向。
- `FILM_PIPE_PORTS.json`：管道段穿过土建结构的开孔检查。此检查不等同于管道制造或水力验算。
- `FILM_HYDRAULICS.json`：工艺节点覆盖、102 段管线及各自依据。图论可达只是其中一项，不代替视觉检查。
- `FILM_SECONDARY_FLOOR.json`：共享二沉池斜底板三个半径位置的实体射线命中。
- `film-preview/`：带水和隐藏水体的 Cycles 预览及动画审计结果。

## 保留的假定

PDF 已标明的主线 DN 按图设置；未标注支管管径、所有管线竖向标高和局部池内集配水构造仍是演示假定。接触池保留现有四折流单池构造，通过池内出水收集管接到东侧；不据平面总图推导未经给出的水力剖面。NAOCL 处图面主水线与加药建筑重叠，模型将主水线避让至建筑外、加药独立接入，未把主水建成穿越药剂储存间。虚线检修/定位包络不直接当作实体池壁外边线放大。

这是工艺演示工程，未做 CFD、全厂纵向水力计算或厂家设备内部复原。完整 4K 长片与闪烁验收需在目标渲染终端执行。
