# 任务日志

> **任务前先阅读上一次提交的日志报告**

任务日志记录每轮工作的实际范围、采用口径、核验结果和遗留事项，供后续成员及 Agent 接续工作。日志日期对应工作的发生日期；因交接需要事后整理的日志，必须在正文中标明补记日期，不能把补记误写成历史提交。

## 阅读顺序

按日期倒序阅读，开始新任务前至少读取最新一份：

1. [2026-09-12：计算说明书补算、排版与最终核验](2026-09-12.md)（2026-09-13 补记）
2. [2026-09-11：定稿方案、标准核查与数值初轮](2026-09-11.md)（2026-09-13 补记）

旧日志和分项计算可用于追溯判断过程；当前设计参数及交付状态以最新日志和 [`计算成果/提交版/`](../计算成果/提交版/) 中的整体成果为准。

## 建议记录内容

- 本轮任务目标和实际修改范围；
- 读取的任务书、标准、教案或厂家资料；
- 采用的设计值、课程假设及其适用边界；
- 计算、图文、版式和文件检查结果；
- 仍需用户、实测、厂家或后续设计确认的事项；
- 与上一版不同的关键参数及旧成果的历史属性。
