# 污水处理厂课程设计项目

本仓库用于保存污水处理厂课程设计的交接资料、原始依据、计算成果和小组协作记录，供组员及其 Agent 共同查阅、修改和审核。

## 项目目标

按照任务书和教案要求，完成污水处理厂课程设计。项目采用“分项推进、逐项审核”的方式：当前计算项目完成并经用户确认后，才进入下一项目。

当前交接点为第 3 项：工艺方案与设计参数确定。

## 快速开始

开始工作前，请按以下顺序阅读：

1. [`AGENTS.md`](AGENTS.md)：Agent 协作规范和修改边界；
2. [`hand_off.md`](hand_off.md)：当前交接状态、已通过口径和下一步任务；
3. [`计算成果/计算进度.md`](计算成果/计算进度.md)：各计算项目的进度；
4. [`计算项目大纲_待确认.md`](计算项目大纲_待确认.md)：项目顺序和成果要求；
5. [`资料索引/阅读索引.md`](资料索引/阅读索引.md)：原始资料、页码映射和查阅顺序。

第 2 项已通过的进水负荷和最低去除率：

| 指标 | 原水平均浓度 | 全厂平均日负荷 | 任务书出水限值 | 最低去除率 |
| --- | ---: | ---: | ---: | ---: |
| BOD₅ | 166.67 mg/L | 18000 kg/d | 20 mg/L | 88.0% |
| SS | 277.78 mg/L | 30000 kg/d | 20 mg/L | 92.8% |

氨氮、COD、碱度及初沉去除率不是任务书直接给定的实测输入。后续如需采用，必须明确标注为工程假定，并说明依据、敏感性和复核点。

```text

├── CONTRIBUTING.md           # Issue、PR 和审查指南
├── hand_off.md               # 当前交接说明
├── 计算项目大纲_待确认.md      # 计算项目总顺序和边界
├── 计算成果/                  # 分项目计算成果
└── 资料索引/                  # 原始资料索引、摘录和页码核对图
```

仓库根目录中的 PDF、DOC 和图片是随交接包保存的原始依据或参考材料。不要覆盖或重命名原始资料；新增摘录、核对图和缓存应放在 `资料索引/` 的相应子目录。

## 计算成果写作要求

每个项目按以下顺序组织：

1. 参数及依据；
2. 公式与符号；
3. 数值代入；
4. 取整或设备选择；
5. 工况校核；
6. 结果表、流程图或草图；
7. 待审核事项。

引用原始资料时，尽量注明文件名、书内页码、PDF 页码、表号或条款，并区分题设原始数据、已通过口径、工程假定和待补数据。

## Agent 和小组协作

- 一次只推进一个计算项目。
- 当前项目未获用户明确通过前，不得开始下一个项目。
- 开始修改前检查 `git status`，避免覆盖他人的未提交修改。
- 一个提交尽量只对应一个逻辑任务，不混入无关格式化。
- 优先使用分支和 Pull Request 协作，避免直接覆盖他人的工作。
- 不使用强制推送，不执行 `git reset --hard`，不批量删除他人文件。
- 不提交 Token、密码、Cookie、临时文件或个人本机敏感路径。

详细规则见 [`AGENTS.md`](AGENTS.md) 和 [`CONTRIBUTING.md`](CONTRIBUTING.md)。

## 审核与交接

成果文件在用户审核前使用“待审核”状态。完成一个项目后，应同步更新 `计算成果/计算进度.md`，并在回复或 PR 描述中说明：

- 修改了哪些文件；
- 使用了哪些依据和假定；
- 如何进行验证；
- 哪些问题仍需要用户确认。

项目设计不是自动定稿流程；任何影响设计边界、已通过口径或构筑物设置的变更，都需要明确记录并等待审核。

## 资料查阅提醒

两本大扫描手册应通过 `资料索引/阅读索引.md` 定位后按需查阅，不要对整本文件做全文 OCR 或无目的重复扫描。引用扫描资料时保留可追溯的页码和条款信息。
